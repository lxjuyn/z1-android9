# Z1 R7 R4: lock screen gate and Bluetooth direct H4

Host verified; not flashed. This is the exact boot image from the R3 lock-screen gate candidate (f07c832) paired with the Bluetooth direct-H4 system (98c845a). See `SHA256SUMS`. The scatter enables only bootimg and android in Download Only. Keep the R3 boot and system as rollback. No calibration records or user files are included in this overlay.

Observed on R3: WMT and STP opened successfully, but the factory userspace code reported NVRAM restore not ready and closed the controller. The replacement adapter keeps the factory path when it succeeds and otherwise hands `/dev/stpbt` to Android's H4 stack. This does not restore factory NVRAM; verify HCI initialization, the board's Bluetooth identity, discovery, pairing, reconnect and Wi-Fi coexistence. A2DP requires separate testing.

Verify boot stability before enabling Bluetooth. Separately verify automatic and power-key lock goes physically dark and displays a new frame on wake. The lock screen change does not address the earlier abrupt SoC resets.

The copied images match the verified input hashes, e2fsck -fn passed, and readback of libbt-vendor.so and mtk_btif_drv.ko from the combined package matched their source hashes.
