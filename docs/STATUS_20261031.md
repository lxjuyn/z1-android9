2. **zygote AIOOBE 崩溃**：`Build.java:288 ALL_CODENAMES[0]`，属性 `ro.build.version.all_codenames` 读回空（/dev/__properties__ 间歇损伤）。修复=/etc/prop.default 防弹属性（板上验证：zygote 单次零崩溃）。✅ 已解决
3. **vendor execve 全灭（ENOENT ×990）**：仅出现在 r5k_swift 镜像（cp+mount+**sed** 构建）——同法构建的 r5k_pd 无此问题（sf3 板上 0 失败）。**嫌疑=sed -i 重命名式编辑**；r5k_pd 系的 debugfs/tee 路径健康。✅ 已绕开（谜团记录在案）
4. **patchoat 冻死（41s）**：boot 镜像（10-06 基线 boot.art/oat）与运行时不匹配 → patchoat 重定位冻死 → zygote 等到天荒地老。修复=/framework/arm 改名 arm.noimage（板上验证：patchoat 0 出现）。✅ 已解决
5. **彩虹条纹**：mesa 渲染件（libGLES_mesa.so）劫持 GLES 装载器 + GPU 416MHz 无 VGPU 电压 → 坏帧。修复=移除 mesa 件（装载器回落 swiftshader 三件套，r5f 实证命名）→ 二屏正确渲染。✅ 已解决（GPU 真加速待 VGPU 电压方案）
